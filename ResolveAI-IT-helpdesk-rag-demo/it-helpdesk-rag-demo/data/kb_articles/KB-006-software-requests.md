## Software Center (self-service)
Standard users do not have administrator rights. Approved software can be installed without admin rights from **Software Center** (Start menu > Software Center). Popular applications include Python, Git, VS Code, Notepad++, Zoom, Adobe Acrobat Reader, Power BI Desktop and 7-Zip.

## Software not in Software Center
1. Submit a Software Request form in the IT Portal with the product name, version, vendor website and business reason.
2. Your manager approves the request.
3. The Security team reviews licensing and security (usually 2-3 working days).
4. Once approved, the packaging team adds it to Software Center.
Free or open-source software still needs a security review.

## Microsoft 365 Apps (32-bit vs 64-bit)
New laptops ship with 64-bit Microsoft 365 Apps. If Excel crashes on very large files, check File > Account > About Excel. If it shows 32-bit, install the 64-bit version from Software Center (this replaces the 32-bit one).

## Temporary admin rights
Developers can request time-limited admin rights (maximum 4 hours) through the IT Portal. Every elevation is logged and reviewed.
